# FitFaat - Gym Management Software

[FitFaat](https://www.fitfaat.com) is gym management software and a mobile app for gyms, fitness studios and sports academies in India: memberships, billing, attendance, CRM, WhatsApp automation and multi-branch control. Used by 1,000+ gyms.
